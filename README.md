# Movie Explorer

A modern and responsive **Movie Explorer** web application built using **HTML5, CSS3, and Vanilla JavaScript**. The application allows users to search for movies, browse trending and top-rated titles, view detailed movie information, and save their favorite movies using Local Storage.
This project demonstrates API integration, asynchronous JavaScript, responsive UI design, and client-side data management.

1. Project Overview
Movie Explorer is a frontend application that consumes a public movie API to provide real-time movie information. Users can search for movies, explore trending content, and access detailed information such as ratings, release dates, genres, cast, and trailers.
The project focuses on learning how to work with REST APIs, asynchronous programming, and dynamic user interfaces.

9. Getting Started
1) Clone the repository

```bash
git clone https://github.com/your-username/movie-explorer.git
```

2) Navigate into the project

```bash
cd movie-explorer
```

3) Configure API Key
Create a configuration file and add your Movie API key.
Example:

```javascript
const API_KEY = "YOUR_API_KEY";
```

4) Run the project
Open **index.html** in your preferred browser.
